# CT投影・画像再構成デモ

Shepp–Loganファントムを使用して、**X線CTの投影処理と画像再構成の仕組み**を体験できるStreamlitアプリです。メディカルAIや医用画像処理の授業で、投影方向・投影数・再構成フィルタが画像に与える影響を視覚的に確認できます。

## 主な機能

### 1. 投影処理とサイノグラムの表示

- Shepp–Loganファントムを表示します。
- 平行ビーム投影（Radon変換）により、サイノグラムを生成します。
- 投影数を設定できます（1～360）。
- 「投影処理開始」を押すと、ファントムの周囲を赤い矢印が回転し、サイノグラムが順番に描画されます。

### 2. 画像再構成

- 0°以上180°未満の投影データを使用し、画像を再構成します。
- 再構成に使用する投影数を設定できます（1～180）。投影データは指定した数だけ等間隔に選択します。
- 「画像再構成開始」を押すと、各方向からの逆投影を順に加算するアニメーションが表示されます。
- 再構成中は、ファントム上の赤い矢印も0°から180°方向へ移動します。

### 3. 再構成フィルタの選択

次のフィルタを選べます。

| フィルタ | 特徴 |
| --- | --- |
| なし（Unfiltered） | フィルタを適用しない単純逆投影。画像がぼけやすい方式です。 |
| Ram-Lak（Ramp） | フィルタ補正逆投影法の基本となるフィルタです。 |
| Shepp-Logan | Ram-Lakと比較して高周波成分を抑えます。 |
| Cosine | 高周波成分を抑えるフィルタです。 |
| Hamming | 高周波成分を抑える窓関数を用います。 |
| Hann | 高周波成分を抑える窓関数を用います。 |

選択したフィルタの**周波数応答**も表示します。グラフには比較用としてRam-Lakフィルタの応答を灰色の破線で重ねて表示します。

## 操作方法

1. 左側の設定欄で、投影処理の投影数を選びます。
2. **「投影処理開始」**を押し、赤い矢印の回転とサイノグラムの生成を観察します。
3. 再構成に使用する投影数と再構成フィルタを設定します。
4. **「画像再構成開始」**を押し、逆投影によって画像が形成される様子を観察します。
5. 投影数やフィルタを変更して、再構成画像の違いを比較します。

## ローカル環境での実行方法

Python環境（Condaなど）を用意し、本リポジトリのフォルダ内で以下を実行します。

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Conda環境を新しく作る場合の例：

```bash
conda create -n medicalai python=3.11 pip -y
conda activate medicalai
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

実行すると、ブラウザからアプリを操作できます。

## 授業での観察例

- **投影数を10、30、60、180と変更**：投影数が再構成画質に与える影響を確認します。
- **フィルタなしとRam-Lakを比較**：単純逆投影のぼけと、フィルタ補正による画質改善を確認します。
- **各フィルタの周波数応答を比較**：高周波成分の強調・抑制と、再構成画像の見え方の関係を考えます。

> このアプリはCT画像再構成の原理を理解するための教育用デモです。臨床用のCT撮影・診断を目的としたものではありません。
